# 커밋

규칙 본문은 `docs/agent/rules/git.md`. 여기서는 순서만 적는다.

## 순서

- `git status`와 `git diff`로 변경을 확인한다. 의도하지 않은 파일(빌드 결과물, `local/`, 비밀값)이 섞여 있으면 뺀다
- 변경을 두세 줄로 요약해 작업자에게 보여 주고 커밋해도 되는지 확인받는다. 확인 전에는 커밋하지 않는다
- 메시지를 만든다
    - `타입: 제목`. 제목은 50자 이내, 마침표 없이, 한국어
    - 타입은 `.gitmessage` 목록에서 고른다. 기능이면 `feat`, 설정과 문서 세팅이면 `chore`, 문서만이면 `docs`
    - 본문은 필요할 때만. 무엇을 왜 바꿨는지
    - `Co-Authored-By`, `Generated with` 같은 서명 줄은 넣지 않는다. 도구가 자동으로 붙이려 해도 뺀다
- 관련 파일만 `git add`하고 커밋한다
- `git log -1`로 메시지를 확인하고 작업자에게 커밋 해시와 제목을 알린다

## 예시

```
feat: 단체 생성/조회 및 운영진 권한 검사
chore: AI 작업 지침 문서와 hook 세팅
docs: 에러 코드 표에 ORG_402 추가
```

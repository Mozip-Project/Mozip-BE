# 결정 기록

기록 기준과 상태 값은 `docs/agent/decisions/README.md`. 여기서는 순서만 적는다.

## 기록할지 먼저 판단

- README의 세 조건(여러 후속 작업에 영향, 대안 사이의 선택, 바꾸려면 여러 파일)을 모두 만족하는지 본다. 하나라도 아니면 PR 본문이나 주석으로 끝내고 기록하지 않는다
- 이미 같은 주제의 기록이 있으면 새로 만들지 않고 그 기록의 "변경 기록"에 이어 쓴다. 완전히 뒤집히면 새 기록을 만들고 옛 기록을 `superseded`로 바꾸고 서로 링크한다

## 작성

- `docs/agent/decisions/records/`에서 마지막 번호를 확인하고 다음 번호로 `NNN-short-title.md`를 만든다
- `template.md`를 복사해 채운다. 맥락은 두세 줄, 결정은 짧은 문장, 대안마다 버린 이유 한 줄
- 근거는 대화나 PR에서 실제로 나온 이유만 쓴다. 없는 이유를 지어 넣지 않는다
- 상태는 상대 담당자가 확인했으면 `accepted`, 아니면 `proposed`
- 관련 줄에 이슈와 PR 번호를 적는다

## 연결

- README 목록 표에 한 줄 추가
- 이 결정이 근거가 되는 `docs/agent/rules/` 문장 끝에 `(결정 NNN)`을 붙인다
- 결정으로 규칙이 바뀌었으면 규칙 문서도 같은 PR에서 고친다
